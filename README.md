# CSCI-2370 3D Transmission Grid Visualization Project
Team Members: Yonas Amha, Aidan LaBella and Korey Sam

## Project Plan
| Week | Task | Deliverables and Outcomes |
|------|------|----------------------------|
| 1–2  | Implement the existing SOTA 2D method [Lyons et al., 2023], get to know the data, collaborators, and develop initial infrastructure. | A replication of what is shown in Figure 2drep, with working codebase. |
| 3–4  | Develop a 3D model of the transmission grid system and begin VR implementation. | A deliverable 3D product that can be shipped to users for evaluation. |
| 5–6  | Conduct evaluation studies with users for 2D and 3D models. | Qualitative and empirical results from user studies. |
